### Para iniciar
---
Todos los comandos deben de ser usados desde la raíz del proyecto y con Node v23 y NPM instalados.

En caso de no tener pnpm instalado:
```
npm i -g pnpm
```
Una vez pnpm este instalado:
```
pnpm i
```

### Iniciar API
Modo desarrollo:
```
pnpm dev:api
```
Modo producción:
```
pnpm build:api
pnpm run:api
```

### Iniciar Aplicación Movil
1. Iniciar simulador AVG (Android Studio).

2. Una vez el simulador haya terminado de iniciar:
```
pnpm dev:mobile
```

# [EN] Citizen Consultation Analysis App
---

### Getting started
---
All commands must be used from the project root and with Node v23 and NPM installed on your system.

In case pnpm isn't installed:
```
npm i -g pnpm
```
Once pnpm is installed:
```
pnpm i
```

### Start API
Developer mode:
```
pnpm dev:api
```
Production mode:
```
pnpm build:api
pnpm run:api
```

### Start mobile app
1. Start AVG simulator from Android Studio.

2. Once the simulator has finished starting:
```
pnpm dev:mobile
```
